# WeSight for Obsidian 1.0.0

这次更新围绕「一篇文章，多种表达」展开：新增图文动态工作台、快速转和浏览器发布助手联动，让文章从创作、改写、配图到平台草稿准备形成更短的流程。

## 新增：一键转为图文动态

- 在 WeSight 顶部、笔记工具栏、文件菜单和命令面板提供「转为图文」入口，打开右侧工作台时保留左侧原文。
- 「快速转」支持小红书、微博图文动态和即刻动态，按选择的平台生成适配文案。
- 可选择多平台统一文案或各平台不同文案，直接在快速转中预览、编辑；需要精细调整时，可跳转到对应平台页签继续修改。
- 提取原文图片并默认推荐部分配图，支持手动选择、横向浏览更多图片和调整顺序；AI 生图和文字配图提供独立入口。
- 生成完成后，可一次交给发布助手准备所选平台的内容；完成一轮后支持重新发起准备任务。

## 新增：小红书图文创作工作台

- 提供文案、图片、检查三个环节，支持标题、正文、标签编辑及标题长度检查，并自动保存本地草稿。
- 文字排版采用统一文字编辑区，一句或一段均可；支持逐页编辑及一次生成多页文字，切换二级样式时保留文字内容。
- 提供多种文字模板、手写字体、居中排版、光影效果和自动关键词强调。
- 其他图片风格使用独立 AI 图片画廊，覆盖实拍摄影、杂志拼贴、插画叙事、信息图解和截图讲解。
- 支持图片放大、单张重新生成、追加图片、顺序调整，以及 3:4、1:1、4:3 比例；可使用文章图片或本地图片作为参考。

## 新增：多平台文章草稿准备

- 分享面板新增「多平台」，支持知乎、CSDN、掘金、B站专栏、今日头条和微博头条文章。
- 配套浏览器扩展复用浏览器登录状态，上传图片、填充内容，并保留各平台编辑页供人工检查。
- 提供发布助手下载、解压安装、扩展管理页、开发者模式和首次配对引导。
- 显示各平台任务状态，支持打开编辑页、登录后重试，以及失败后的恢复。

## 体验改进与问题修复

- 修复公众号草稿同步后预览页可能持续显示加载状态的问题。
- 改进文章图片提取和快速转多平台任务映射，避免多选后只准备一个平台。
- 修复文字模板二级样式选择后的滚动定位，改善页数编辑和生成图片预览。
- 配合发布助手 1.0.0，改进微博与即刻上传完成状态识别、即刻空行，以及平台标签格式：小红书使用 `#标签`，微博使用 `#标签#`，即刻不追加标签。
- 普通用户支持单平台转换及草稿准备；有效会员支持多平台批量操作。仅在主动尝试多选时显示页内会员提示，保留当前文案和图片；默认进入页面不展示会员提示。

## 升级与使用说明

- 请同时更新到 [WeSight 发布助手 1.0.0](https://github.com/freestylefly/wesight-chrome/releases/tag/v1.0.0)，旧版扩展不包含新增平台和快速转批量任务支持。
- [Chrome 安装包](https://github.com/freestylefly/wesight-chrome/releases/download/v1.0.0/wesight-chrome.zip) · [Edge 安装包](https://github.com/freestylefly/wesight-chrome/releases/download/v1.0.0/wesight-edge.zip)。解压后在扩展管理页加载，并在更新后重新加载扩展。
- 手动安装 Obsidian 插件时，使用本 Release 的 `main.js`、`manifest.json`、`styles.css` 替换插件目录中的对应文件，再重新加载插件。最低支持桌面版 Obsidian 1.11.4。
- 图文生成使用所配置的兼容引擎；AI 生图需要引擎具备图片生成能力，调用费用遵循对应服务的配置。
- 发布助手通过本机 `127.0.0.1` 临时通道接收内容，这条传输链路不经过 WeSight Cloud。AI 生成会按所选引擎配置向模型服务发送输入；公众号草稿和互联网分享仍沿用原有云端流程。
- 所有平台均停留在可人工检查的编辑页，最终「发布」由你点击。使用期间请保持 Obsidian 打开；平台页面变化可能需要后续适配更新。
